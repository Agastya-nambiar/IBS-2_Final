v36 CHANGES FROM v37
======================================================================
1. FIXED validation leakage: blend weight / isotonic calibration / threshold / top-4
   meta-model selection now all fit on a "cal" split of Validation.csv only; "holdout"
   is untouched until the metrics above. v37 fit and reported on the same rows, which
   inflates the reported score.
2. FASTER: swapped GradientBoostingClassifier -> HistGradientBoostingClassifier for the
   slow base model (was the single biggest time sink - ~50 min for 5 Optuna trials
   alone). Trial budget raised to 20 since it's cheap now.
3. FIXED: RF/XGB/ET/LGBM were losing random_state, n_jobs, and their class weighting
   when rebuilt from `study.best_params` for the real training run. Restored - training
   now matches what was actually tuned, and RF/ET run multi-core again.
4. The trad/deep blend weight is now grid-searched to directly maximize F1 on the cal
   split instead of a fixed AUC-ratio heuristic.
5. GitHub token now comes from the GITHUB_TOKEN environment variable, never hardcoded.
6. Misc: O(1) dict lookup for tripeptide counting (was an O(n) list .index() call per
   hit), shallow clone for the embeddings download, dropped the unused
   facebookresearch/esm install and a dead Ridge/MLP meta-meta step, removed the
   deprecated XGBoost `use_label_encoder` argument.
